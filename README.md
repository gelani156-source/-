# Stack 3.0 — R0 (защита данных и аудит)

Это **отдельный набор инструментов**, а не новая версия текущего приложения Stack. Он не заменяет исходники Stack 2.x и не изменяет IndexedDB. Причина: исходный репозиторий Stack 2.x не был доступен на момент сборки.

## Что уже реализовано
- Анализ структуры JSON-резервной копии **без изменения данных**.
- Контрольная сумма SHA-256 файла.
- Отчёт со структурой и количеством записей верхнеуровневых массивов (значения операций не выводятся).
- Проверка JSON локально в браузере (при наличии WebCrypto и локального HTTP-сервера) и через Node.js CLI.
- Статическая инвентаризация исходников проекта; тесты; пример CI.

## Быстрый запуск
Требуется Node.js 20+.

```bash
npm test
node tools/audit-project.mjs /путь/к/Stack2 --report ./audit.json
node tools/verify-backup.mjs /путь/к/backup.json --report ./backup-report.json
```

**Важно:** `--report` НЕ перезаписывает существующий файл. Не передавайте персональные резервные копии публичным сервисам.

Для браузерного просмотра:
```bash
python -m http.server 8080
```
Затем открыть `http://localhost:8080` с того же компьютера. При отсутствии WebCrypto нужен `localhost` или HTTPS.

## Что ещё НЕ сделано
- Аудит реальных исходников и схемы IndexedDB Stack 2.x.
- Фактический backup/restore тест на отдельном профиле.
- Реальная миграция или интеграция с UI Stack.
- Сравнение балансов, транзакций, категорий и связей до/после миграции.

Не используйте эту утилиту как подтверждение корректности восстановления. Для входа в R1 нужны исходники Stack и анонимизированный тестовый экспорт в формате текущего приложения.

## Безопасность
Все инструменты R0 работают **только на чтение** применительно к существующему Stack. JSON-отчёт содержит имена полей и размеры массивов, иногда косвенно чувствительные сведения; храните его локально. Встроенная HTML-страница не использует серверные API и не отправляет файл по сети.
