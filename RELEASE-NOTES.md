# Stack 1.2 — единая обновлённая сборка

## Включено
- Три явных варианта темы: светлая, тёмная, системная; выбранный вариант сохраняется в IndexedDB.
- Голосовой сценарий: кнопка записи в совместимом браузере → распознавание → форма подтверждения операции. В iOS, если браузерное распознавание отсутствует, доступна диктовка системной клавиатуры в текстовое поле → кнопка «Проверить операцию».
- Загрузка USD/EUR из публичного зеркала данных ЦБ, дата курса и источник; ручные курсы при отсутствии сети.
- JSON и зашифрованные AES-GCM резервные копии, проверка, импорт, напоминания. Подтверждение сохранения файла теперь отдельно от начала скачивания.
- Service Worker: network-first для документа и ресурсов, офлайн-запасная копия, новая версия кэша.
- Готовый `.github/workflows/main.yml` для статического GitHub Pages, без npm build.

## Проверки и реальные ограничения
- Автоматические тесты доменной логики, резервных копий и PWA: 19/19.
- Проверки на реальном iPhone и опубликованном GitHub Pages не выполнены.
- Встроенное распознавание речи определяется реальными возможностями браузера; гарантировать работу микрофона в Safari/PWA нельзя. Диктовка системной клавиатуры служит доступной альтернативой.
- Курсы валют зависят от доступности внешнего источника, HTTPS и CORS.
- Никакой браузер не гарантирует фактическое сохранение скачанного файла; подтверждение делает пользователь.

## Публикация
1. В отдельном репозитории Stack разместите **содержимое** архива в корне (не папку-обёртку). Не загружайте его в репозиторий OSFIT.
2. Убедитесь, что в `.github/workflows/` только нужные для Stack workflows. Старый workflow OSFIT с `npm run build` отключите либо удалите **только из репозитория Stack**.
3. Settings → Pages → Source: GitHub Actions.
4. Перед обновлением экспортируйте резервную копию. Не удаляйте PWA, не очищайте данные сайта.
