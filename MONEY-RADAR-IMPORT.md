# Полный перенос Money Radar → Stack 1.3

1. В Scriptable создать скрипт **Money Radar FULL Export** из `Money_Radar_FULL_Export_to_Stack.txt` (текстовый файл предоставляется отдельно).
2. Запустить его и сохранить JSON через «Файлы». Исходная база `money-radar-data.json` не меняется.
3. **До обновления Stack сохранить полную резервную копию Stack.** Не удалять PWA и не очищать Safari.
4. Загрузить содержимое архива Stack 1.3 в репозиторий Stack (не OSFIT), включая `money-radar-migrate.js`, перезапустить приложение после публикации.
5. В Stack: **Ещё → Импорт данных**; выбрать новый JSON. Выбрать существующий рублёвый счёт и подтвердить импорт.
6. По желанию выбрать перенос бюджетов на текущий месяц (заменит бюджет этого месяца). Начальный баланс по умолчанию не переносится, чтобы избежать двойного учёта; его нужно включать только при понимании схемы баланса.
7. Проверить результаты: «История», «Долги», «Цели», «Платежи», «Шаблоны», «Бюджеты» и итоговый баланс.

## Особенности и ограничения
- Money Radar 7.x использует `transactions`, `loans`, `goals`, `recurring`, `templates`, `sectionBudgets`, `initialBalance`. Счета Money Radar не создаются автоматически: все операции привязываются к выбранному рублёвому счёту.
- Долги из Money Radar трактуются как **«Мне должны»**, кроме записей с явно указанным направлением `owe`; связь с чеком Money Radar сохраняется в дополнительном поле, но автоматически не становится связью Stack. Это предотвращает ошибочные денежные списания.
- Другие, незнакомые поля и настройки остаются в оригинальном JSON внутри экспортного файла, но не активируются в Stack: их модель может отличаться.
- Существующие операции сопоставляются по типу, дате, заметке, сумме и счёту. Если после предыдущего переноса пользователь отредактировал заметки, возможны несовпадения; проверьте предварительную сводку.
- Повторный импорт не должен повторно переносить известные сущности, а повторное добавление начального остатка блокируется.
- Установленное PWA и его данные на реальном iPhone не тестировались в этой среде. Автоматические unit-тесты пройдены.
