# Stack Widget 1.8

Установите `Stack_Widget_Scriptable.js` в Scriptable как `Stack Widget`. На iPhone откройте Stack → Ещё → Виджет Scriptable → Передать данные. Затем выберите Scriptable-виджет (средний или большой).

Виджет показывает баланс, остаток, расходы месяца и горизонтальную диаграмму 3/5 крупнейших категорий. Маленький виджет показывает основные суммы. Сведения сохраняются в Scriptable, обновление — только после передачи из Stack, не фоновое. Данные старше 36 часов помечаются предупреждением. Не делитесь ссылками передачи: они содержат финансовые показатели.
