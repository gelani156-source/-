# Stack 1.4 — виджет Scriptable

1. В Scriptable создать скрипт с ТОЧНЫМ именем `Stack Widget` и вставить содержимое `Stack_Widget_Scriptable.js`.
2. Открыть Stack на iPhone, разблокировать и выбрать «Обновить виджет» на главной странице либо «Ещё → Виджет Scriptable».
3. Разрешить запуск Scriptable, после импорта добавить большой Scriptable-виджет на главный экран и назначить ему `Stack Widget`.
4. Для обновления показателей повторно нажимать «Обновить виджет» в Stack.

## Ограничения

Это синхронизация снимка **по запросу пользователя**, не фоновая двусторонняя синхронизация. Scriptable не имеет прямого доступа к IndexedDB Safari/PWA. Краткая сводка (баланс, свободно, дневной лимит, доходы, расходы и до 5 операций) передаётся в Scriptable по URL-схеме, без сервера. Не создавайте публичные скриншоты ссылок с параметрами — они содержат финансовые показатели.

## Быстрый запуск

Увеличена версия кэша и HTML/JS ресурсов, чтобы старые ресурсы не смешивались с новыми. Предыдущие функции не удалены. **Ускорение измерением на реальном iPhone не подтверждено**: для надёжного улучшения потребуется профилирование IndexedDB/рендеринга.
