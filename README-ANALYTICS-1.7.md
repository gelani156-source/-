# Stack 1.7 · Банковская аналитика

- Периоды: 7/30/90/365 дней, месяц, вся история.
- Фильтры раздела, категории, счёта, текста операции.
- Диаграмма расходов, суммы/доли категорий, переход в операции.
- Аудит подозрительных категорий из аналитики и раздела «Ещё» (без изменения истории).
- Консервативные подсказки категорий для умного ввода; категории подтверждаются вручную.
- «Поездки» и «Спорт» включены в начальный перечень **новых** баз. Существующие базы не изменяются автоматически; добавьте категории через «Ещё → Категории».
- Переводы исключены. Возврат долга — доход, а не отрицательный расход категории. Если операция отнесена к неверной категории, исправьте её в истории.
- Важно: группировка зависит от уже сохранённых категорий. Программа не может достоверно восстановить назначение старой операции по одной сумме.
