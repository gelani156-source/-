# Stack 2.1 — объединённый редизайн

Включено: дизайн главной, истории, банковской аналитики, настроек, модальных форм и навигации; иконки в стиле OSFIT, виджет категорий Scriptable из версии 1.8.

**Сохранность:** доменная логика, база IndexedDB, миграции, шифрованные архивы, расчёты и импорт Money Radar не заменялись. Перед обновлением сохранить резервную копию JSON.

**Виджет:** обновляется после передачи снимка из Stack; автоматической связи с браузерной базой нет.

**Установка:** распаковать архив, загрузить содержимое (не ZIP) в корень репозитория GitHub Pages, выполнить Commit & Push. Кэш может обновиться после перезапуска PWA.

**Тесты:** `npm test`. Автотесты не заменяют ручное тестирование на iPhone.
